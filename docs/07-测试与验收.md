# 测试与验收

## 测试金字塔

### 单元与属性测试

- Line Protocol 兼容 parser、Protobuf frame parser、Gzip 有界解压。
- 枚举、UTF-8、时间、map/字段/事件/批次限制。
- 认证 scope、constant-time key verifier、PII 规则。
- OTLP 映射快照、数值注册表和错误降级。
- 重试、退避、lease owner、过期重领和状态机。
- Hypothesis/fuzz corpus 覆盖截断、随机长度、压缩炸弹和未知字段。

### PostgreSQL 集成测试

- 同 batch 内重复、历史重复、两个连接并发插入相同 eventId。
- 整批原子性：第 N 条失败时零插入。
- worker `SKIP LOCKED` 不重复认领；非 owner 不能完成；lease 到期可重领。
- RLS/tenant repository 的跨租户负向测试。
- 迁移从空库、前一版本升级、回滚边界和索引计划。

### 契约与端到端

- 使用 Android 客户端生成的真实 Line/Protobuf/Gzip fixture，不手写替代。
- 真实 `HttpApmUploader` 指向 Gateway：2xx 后客户端 ACK；故意丢 ACK 后重传只形成一条事实。
- OTLP mock 验证 wire bytes；SigNoz staging 验证日志/指标可查询。
- Dashboard 合成数据验证过滤器、单位、空数据、告警触发/恢复。
- mapping/Native fixture 验证正确、错误和缺失 build-id。

2026-07-31 已完成其中的本机 V2 兼容闭环：JDK 17 编译并运行真实 `HttpApmUploader`，通过 loopback HTTP 发送 Gzip `ApmBatchEnvelope` 到运行中的 FastAPI Gateway；客户端验证精确 schema/batch/count ACK，同批重放后测试用 SQLite inbox 仍为 2 个唯一 eventId，并核对 12 种 typed scalar、resource 和协议元数据。该证据验证客户端/服务端 wire 兼容性，不替代 PostgreSQL 并发/事务、TLS ingress、代理丢 ACK、真实 SigNoz 或生产部署验收。复现命令在 Android 客户端仓库执行：

```powershell
python tools/verify_collector_e2e.py `
  --server-repo D:\path\to\AndroidAPM-Server
```

## 故障注入

- PostgreSQL 在 commit 前/后断连，确认不会错误 ACK。
- Gateway 处理完成但反向代理丢响应，确认客户端重放幂等。
- SigNoz/网络 429、5xx、超时、慢响应、永久 4xx。
- worker 杀进程、时钟偏差、lease 过期、重复 worker。
- 磁盘接近满、连接池耗尽、inbox 高水位、对象存储不可用。
- 密钥撤销缓存、轮换重叠、跨 tenant/app/env 尝试。

## 性能与长稳

初始基准场景：32 events/batch、1 KiB/event，分别测试纯 Line、Protobuf、Gzip。记录吞吐、ACK P50/P95/P99、CPU、RSS、数据库连接/IO/WAL、inbox 增长和 worker 可见延迟。结果必须注明硬件、并发、数据分布和命令。

发布前执行至少 2 小时稳态 + 峰值压测和 72 小时 soak。容量模型用实测而不是框架宣传；若单实例 Python Gateway 在目标硬件无法满足预算，先剖析解析/数据库瓶颈，再依据 ADR 触发 Go/Rust 数据面评估。

## 安全验收

- SAST、依赖/镜像漏洞、secret scan、SBOM、许可证清单。
- OWASP API 测试：认证绕过、对象/函数越权、资源消耗、注入、SSRF、错误信息泄漏。
- 跨租户读写是零容忍发布阻断。
- 日志扫描确认 Authorization、原始 key、未脱敏 body 不出现。
- 备份恢复与数据删除请求有真实演练证据。

## 发布门禁

P0：格式/静态检查、单元、PostgreSQL 集成、迁移、契约、镜像构建、secret scan 必须全绿。P1：SigNoz staging E2E、告警、备份恢复、故障注入和性能预算必须在生产发布前完成。外部资源不可用时，状态写“待执行/被何物阻塞”，不得写“通过”。
