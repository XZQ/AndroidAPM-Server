# 本地产品功能与操作

2026-11-02 当前实现：性能、告警、设置、Trace 路由已接入真实 API；admin 可使用调查入口及受 CSRF 保护的管理操作。当前 SDK 尚未提供标准 session/device/OS、session_start 和 span v2 起止；相应服务端功能由合格输入驱动，真实旧 SDK 数据保持 unavailable/unknown/timing unavailable。下述支持不表示 SDK 已自动采集，也不表示生产部署通过。

## 当前可用功能

`main` 是本地和 GitHub 唯一分支，保留原完整实现线历史。性能、告警和设置均已替换能力缺口页。

| 页面 | 可执行功能 |
| --- | --- |
| 总览/发布/Issues | Java/Native Crash、ANR、单列 Tombstone 数量/趋势/指纹；质量门禁与标准运行会话率；设备/OS/场景分布及缺失覆盖 |
| 性能 | 243 个精确数值契约、66 种事件和 29 个类别，覆盖 13 个性能域及 SDK 自健康；P50/P75/P95、平均/极值、覆盖、缺失/无效/不可用样本、版本差值、趋势、网络失败/Jank 比例与按窗口时长加权 FPS |
| Trace | investigator/admin 手动 Trace 列表、Span 层级/真实时间线、孤立/重复/循环 ID 与旧 span 的时间缺失状态，受审计事件下钻 |
| 告警 | 创建/编辑、启用/停用、版本与窗口限定、最少样本、上下阈值、自动/手动评估、触发/恢复实例、确认、静默、通知去重/有界重试与送达状态 |
| 设置 | 应用名称、三类凭据创建/撤销/到期与角色、一次显示 secret、有效运行参数/Inbox/符号任务、制品元数据、Ed25519 签名配置发布、灰度、历史和递增 revision 回滚、scope 限定审计 |

性能数据源是 durable inbox，所有查询有限额。分位数表示上报观测分布；`averageFrameMs` 等聚合字段的分位数不等于单帧分位数。未绑定发生时版本的兼容数据不进入版本性能比较。超过 10,000 默认观测时缩小时间窗，不返回截断样本。实时告警默认每 30 秒评估，Web 支持刷新。

## Windows 本地启动

```powershell
.\scripts\start-local.ps1 -ClientRepo D:\BaiduSyncdisk\workspace\AndroidAPM
```

已安装依赖时可加 `-SkipSync`；仅准备环境、迁移和测试数据用 `-PrepareOnly`，已有本地凭据/数据时用 `-SkipSeed`。脚本识别 PATH 的 uv 或仓库 `.local/uv-bootstrap/bin/uv.exe`，构建 Web、执行九版迁移及历史投影升级、生成独立本地 HMAC/Ed25519 密钥，启动 API、告警和保留维护。Ctrl+C 退出时停止附属进程。API 绑定 `127.0.0.1:8080`。

打开 `http://127.0.0.1:8080`，从忽略文件 `.local/local-credentials.json` 取得一天有效的 admin Query Key。演示数据明确为 synthetic，用于功能验收。Ingest Key 与 Query Key 分离，均不打印到自动化日志。脚本生成 `.local/apm-collector.properties`，`-ClientRepo` 将其复制到客户端仓库忽略文件；Release 构建不包含这些本地密钥。

## Android Sample 接通

```powershell
adb reverse tcp:8080 tcp:8080
# 在 AndroidAPM 仓库执行
.\gradlew.bat :apm-sample-app:installDebug
```

Sample debug 从 `apm-collector.properties` 读取 Collector scope/短期 key 与远程配置公钥；使用 V3、发生时版本/构建/variant、app-private 稳定 installation、SQLite outbox、Gzip 和 exact ACK。配置 Provider 验证签名并驱动已有 kill switch、模块开关与采样/限流键。没有本地配置时仍使用 Logcat；离线 soak 模式优先，零 SDK control 不初始化。示例当前 APK 版本为 `2.0.0`；构建另一个版本后可在总览/发布页面选择对应基线。

HTTP 仅属于 debug 本地联调，签名配置 HTTP 地址使用 loopback，因此设备需 `adb reverse`。生产切换真实 HTTPS 和 PRODUCTION_STRICT。真实设备安装、启动和采集仍需要连接设备；跨仓库 Java/Kotlin uploader 测试不替代设备运行。

## 告警与通知

计数规则 `crash.count` 是 Java Crash；`native_crash.count` 是现场 Native Crash；`native_tombstone.count` 是历史 Tombstone 证据。`app_exit` 不污染现场计数。性能规则使用目录指标的 `.p95`；样本不足或字段不完整时状态为 INSUFFICIENT_DATA，已有实例保留到可靠的后续恢复观测。

本地没有真实通知渠道时选择“仅控制台”。需要 Webhook 时由服务器管理员设置：

```dotenv
APM_NOTIFICATION_CHANNELS_JSON={"ops":{"url":"https://your-notification-service.example/alerts","headers":{"Authorization":"configured-in-local-environment"}}}
APM_ALERT_POLL_SECONDS=30
APM_NOTIFICATION_MAX_ATTEMPTS=5
```

这是配置结构示例，不是已配置的渠道。目的地可以是邮件/IM 通知网关；浏览器不会获得其 URL 或鉴权头。429/408/5xx 和传输错误按有界指数退避重试，其他拒绝明确 FAILED。接收服务应以 `Idempotency-Key` 去重。

## 权限和边界

- CLI `androidapm-admin create-query-key ... --role admin` bootstrap；Web 只能创建当前 tenant/app/environment 的 Query/Ingest key，以及当前 tenant/app 的 CI key。
- 当前登录 admin key 不能直接撤销，先用新 admin 登录再撤旧 key。其他 key 撤销后现有 Web 会话立即失效。
- 配置回滚读取当前 scope 内历史 payload，签名为递增的新 revision；管理审计不记录正文或 secret。
- 运行/保留参数展示的是服务器有效配置，变更环境参数后重启生效；未提供没有运行作用的假开关。
- 历史列表明确限最近 100 条，凭据每类最多展示 200 条，规则每个 scope 最多 100 条。
- UI 深链接刷新可恢复，未知 API/页面仍为 404。
- 标准匿名 session/device/OS 与手动 Trace/OTLP Metrics/Traces 已实现。旧缓存、跨窗口 session 或不满足 SDK/采样质量时比例仍保留不可用原因，详见 [统计契约](12-统计契约与口径.md) 与 [ADR 0011](adr/0011-运行会话统计与多信号导出.md)。SSO、生产 PostgreSQL/SigNoz/TLS/KMS 和真实通知需环境准备后验收。

## OTLP 三信号

本地查询页面直接读取 Inbox，不依赖 SigNoz。外部 Collector 就绪后设置 `APM_EXPORT_ENABLED=true`、`APM_OTLP_METRICS_ENABLED=true`、`APM_OTLP_TRACES_ENABLED=true` 和相应 `/v1/logs`、`/v1/metrics`、`/v1/traces` endpoint；后两项默认 false。Metrics 为已上报 Gauge 观测，Trace 只导出 schema v2 的真实起止；不凭日志构造 Histogram 或旧 Span 起止。三信号按原计划逐项记录成功进度，重试只执行剩余项。已送达事件不会自动重新导出。
